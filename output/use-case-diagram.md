# Use Case Diagram: Task Manager System

```text
=========================================================
  ДИАГРАММА ВАРИАНТОВ ИСПОЛЬЗОВАНИЯ (USE CASE DIAGRAM)
=========================================================

  [ Актёр: Пользователь (User) ]
                 │
                 ├── (UC-1: Добавить задачу)
                 ├── (UC-2: Удалить задачу)
                 ├── (UC-3: Просмотреть список задач)
                 └── (UC-4: Отметить выполнение задачи)
                                 │
                 ┌───────────────▼────────────────┐
                 │     Система: Монолит To-Do     │
                 │ (Вся бизнес-логика и хранилище)│
                 └────────────────────────────────┘
```

## Спецификация актеров и прецедентов
- **Основной актёр:** Пользователь (User / QA / Developer).
- **Прецеденты:**
  1. **Add Task:** Создание новой задачи с валидацией входных данных.
  2. **Delete Task:** Удаление задачи по уникальному ID.
  3. **View Tasks:** Просмотр списка задач с фильтрацией и статусом.
  4. **Mark Completed:** Изменение жизненного цикла задачи на 'Завершено'.
